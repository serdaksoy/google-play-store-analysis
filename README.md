# Google Play Store Data Analysis (EDA)

This project focuses on identifying market trends within the Google Play Store by analyzing app categories and their installation performances.

## 🚀 Key Features
* **Data Preprocessing:** Cleaned the dataset and handled data type conversions (Installs, Category).
* **Category Analysis:** Analyzed the frequency of app categories and identified the most installed sectors.
* **Top Performance Visualization:** Visualized the top 5 most installed apps within the leading categories to showcase market leaders.
* **Distribution Insights:** Analyzed the distribution of Free vs. Paid apps and Content Ratings using KDE and Count plots.

## 🛠 Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📊 Summary of Findings
* Identified the top categories by total installations (e.g., Game, Communication).
* Visualized the dominance of top apps within high-traffic categories through bar charts.
